# Alugar ou comprar?

Uma calculadora simples para comparar o custo estimado de alugar um equipamento com o preço de compra.

## O que ela faz

- Compara aluguéis cobrados por dia ou por mês.
- Calcula o custo total para o período de uso informado.
- Mostra a diferença entre alugar e comprar, além de uma estimativa do ponto de equilíbrio.
- Funciona em celular e computador, sem cadastro ou dependências externas.

## Como funciona

A calculadora multiplica o valor do aluguel pelo período escolhido e compara o resultado com o preço de compra. O ponto de equilíbrio é estimado dividindo o preço de compra pelo valor da tarifa de aluguel.

**Exemplo:** um equipamento de R$ 3.500,00 alugado por R$ 250,00 ao mês durante 6 meses custa R$ 1.500,00 em aluguel. Nesse cenário, o aluguel fica R$ 2.000,00 abaixo do preço de compra.

> A estimativa considera somente os valores informados. Frete, taxas, manutenção, seguro, depósito, descontos e valor de revenda não estão incluídos. Confira as condições reais antes de decidir.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Informe o preço de compra, a tarifa, a unidade de cobrança e o período de uso.

## Tecnologias

HTML, CSS e JavaScript puro. Não é necessário instalar pacotes ou iniciar um servidor.
